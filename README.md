## 📌 Overview
This repository contains a high-fidelity, interactive frontend prototype for the **BizHub Management System**, designed for an electronics and hardware retail/B2B business. 

This mockup serves as the visual and structural foundation (Phase 1) before implementing full CRUD (Create, Read, Update, Delete) operations and backend database logic (Phase 2). It provides a tangible UI to finalize user flows and data presentation prior to backend API development.

## ✨ Key Features (Current State)
*   **Modern UI/UX:** Sleek "Dark Mode" sidebar paired with a clean, high-contrast "Light Mode" workspace.
*   **Dynamic Tab Navigation:** Seamless, zero-reload switching between Dashboard, Sales, Stock, and Analytics views using vanilla JavaScript.
*   **Interactive Analytics:** Integrates **Chart.js** to render animated data visualizations (Trend Lines, Bar Charts, and Doughnut Charts).
*   **Backend-Ready Layouts:** HTML tables and metric cards are structurally designed to consume JSON data arrays easily.

## 🛠️ Technologies Used
*   **HTML5 & CSS3:** Custom styling utilizing CSS variables, Flexbox, and CSS Grid.
*   **Vanilla JavaScript:** Handles DOM manipulation and UI state management.
*   **[Chart.js](https://www.chartjs.org/):** For rendering lightweight, canvas-based charts via CDN.
*   **[Font Awesome 6](https://fontawesome.com/):** For scalable, professional vector icons.
